# Funniest One-Line Performance Review

One original performance review in a single line, at most 140 characters.

Entry: `Performance review: exceeds expectations at looking busy, asks excellent questions, never unmutes by accident on purpose.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
